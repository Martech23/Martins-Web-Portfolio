# Novo portfólio de David Martins

Esta pasta contém a nova versão comercial do portfólio, criada para abordagens no Instagram e conversas pelo WhatsApp.

A versão anterior permanece na raiz do repositório. Para usar esta versão na Vercel, configure **Root Directory** como `novo-portfolio` e mantenha o projeto como site estático, sem comando de build obrigatório.
